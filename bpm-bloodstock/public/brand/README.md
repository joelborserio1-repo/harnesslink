# Brand assets

Drop the BPM Bloodstock logo here named `logo.png` (or `.svg` / `.webp` / `.jpg`):

    public/brand/logo.png

The Nav and footer auto-detect it and use it in place of the built-in SVG
wordmark. SVG is preferred (crisp at any size); a transparent-background PNG
also works. After adding it: `pm2 reload bpm` (or redeploy).
